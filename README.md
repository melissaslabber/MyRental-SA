# MyRental SA

A guided rental-management app for South African private landlords.

## Run locally

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
```

The current version is a working front-end prototype with demo data. Supabase authentication, permanent data storage, secure tenant links, document generation and subscriptions will be connected in the next development phases.

## Deploy to Vercel

Import the GitHub repository into Vercel. Select Vite, use `npm run build`, and set the output directory to `dist`.
